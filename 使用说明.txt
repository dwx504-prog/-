# Word公式图片转换助手

## 功能
- 支持选择多个 `.docx` 文件，或批量导入一个文件夹中的 DOCX。
- 将 Word 原生公式对象（OMath）尝试转换为增强型图元图片并原位替换。
- 输出为新文件，原始文件不会被覆盖。
- 自动统计转换成功数量和失败文件。

## 运行要求
- Windows 10/11
- 已安装桌面版 Microsoft Word（不是仅有 WPS）
- Python 3.10 或更高版本（仅在自行打包时需要）

## 生成 EXE
1. 将整个文件夹复制到 Windows 电脑。
2. 安装 Python，安装时勾选 `Add Python to PATH`。
3. 双击 `一键打包成EXE.bat`。
4. 打包完成后，在 `dist` 文件夹中找到 `Word公式图片转换助手.exe`。
5. 以后可直接运行 EXE，不需要打开代码。

## 使用
1. 打开工具，添加一个或多个 DOCX 文件。
2. 选择输出目录。
3. 点击“开始转换”。
4. 转换结果以“原文件名_公式转图片.docx”命名。

## 重要说明
- 当前版本针对 Word 内置公式编辑器创建的原生公式（OMath）。
- 如果公式只是普通文字（例如手动输入的 `x^2+1=0`），它不是 Word 公式对象，本版本不会自动识别。
- 复杂公式、受保护文档、损坏文档或某些特殊公式可能无法转换；转换后请抽查公式显示和版式。
- 建议先用文档副本测试。转换使用 Microsoft Word 自动化接口，电脑需安装桌面版 Word。
- 不保证所有文档中的公式都能无损转换；如有失败样本，可提供文档以便针对性适配。
